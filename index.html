Cómo usar la experiencia

Sigue estos pasos para ver el modelo en realidad aumentada.

  1. Descarga o imprime el marcador de la Basílica.
  2. Colócalo en una superficie plana y bien iluminada.
  3. Apunta la cámara al marcador hasta que aparezca el modelo.
  4. Despliega la barra de abajo para mover, rotar o cambiar el tamaño del modelo.

Este es el marcador que debes descargar o imprimir.
